# Погода без реклами та трекерів

**Безкоштовний застосунок погоди для Android з відкритим кодом. Без реклами. Без трекерів. Без акаунта. Близько 80 КБ.**

[English](README.md) · [Українська](README.uk.md) · [Русский](README.ru.md)

Заміна застосункам погоди, де реклами більше, ніж прогнозу. Рідний Kotlin, Android 5.0+, без сервісів Google, без аналітики та рекламних SDK. Увесь код відкритий під GPL-3.0.

**[Завантажити останній APK](../../releases/latest)**

## Можливості

- Анімовані фони для будь-якої погоди: сонце, місяць, зорі, хмари, дощ, сніг, туман, грози
- Погодинний прогноз із графіком температури, прогноз на 10 днів, опади на найближчі 2 години
- Якість повітря (EU та US AQI, PM2.5, PM10, NO2, O3, SO2) і пилок (Європа)
- Вітер із компасом, вологість, тиск, УФ-індекс, видимість, хмарність, опади, світловий день
- Схід і захід сонця, фаза Місяця
- Пошук міст, збережені місця, наближена геолокація (за бажанням)
- Одиниці: °C / °F, км/год / м/с / mph, гПа / мм рт. ст. / inHg
- Легкий для старих і слабких телефонів
- Оновлення: при запуску перевіряє GitHub Releases і пропонує оновитися в один дотик (можна відмовитися)

## Приватність

- Дозволи: `INTERNET`, `ACCESS_COARSE_LOCATION` (наближена, необов'язкова), `REQUEST_INSTALL_PACKAGES` (лише для оновлення в застосунку)
- Залежностей немає, окрім стандартної бібліотеки Kotlin
- Мережа: лише HTTPS, лише до `open-meteo.com` і `github.com`
- З пристрою йдуть лише координати вибраного місця до [Open-Meteo](https://open-meteo.com). Жодних ідентифікаторів пристрою чи реклами

## Встановлення

1. Завантажте `Weather.apk` зі сторінки [Releases](../../releases/latest)
2. Відкрийте файл і дозвольте встановлення, якщо Android запитає
3. Наступні версії оновлюються всередині застосунку
