# Weather without ads and trackers

Native Android weather app (Android 5.0+). No ads, no trackers, no Google services.
Data: [Open-Meteo](https://open-meteo.com) over HTTPS.

- Animated backgrounds for every weather type
- Hourly, 10-day, rain nowcast, air quality, pollen, UV, wind, sun and moon
- Ukrainian, Russian, English
- In-app updates from GitHub Releases

Download: [Releases](../../releases/latest)
