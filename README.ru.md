# Погода без рекламы и трекеров

**Бесплатное приложение погоды для Android с открытым кодом. Без рекламы. Без трекеров. Без аккаунта. Около 80 КБ.**

[English](README.md) · [Українська](README.uk.md) · [Русский](README.ru.md)

Замена приложениям погоды, где рекламы больше, чем прогноза. Нативный Kotlin, Android 5.0+, без сервисов Google, без аналитики и рекламных SDK. Весь код открыт под GPL-3.0.

**[Скачать последний APK](../../releases/latest)**

## Возможности

- Анимированные фоны для любой погоды: солнце, луна, звёзды, облака, дождь, снег, туман, грозы
- Почасовой прогноз с графиком температуры, прогноз на 10 дней, осадки на ближайшие 2 часа
- Качество воздуха (EU и US AQI, PM2.5, PM10, NO2, O3, SO2) и пыльца (Европа)
- Ветер с компасом, влажность, давление, УФ-индекс, видимость, облачность, осадки, световой день
- Восход и закат, фаза Луны
- Поиск городов, сохранённые места, приблизительная геолокация (по желанию)
- Единицы: °C / °F, км/ч / м/с / mph, гПа / мм рт. ст. / inHg
- Лёгкое для старых и слабых телефонов
- Обновления: при запуске проверяет GitHub Releases и предлагает обновиться в одно касание (можно отказаться)

## Приватность

- Разрешения: `INTERNET`, `ACCESS_COARSE_LOCATION` (приблизительная, необязательная), `REQUEST_INSTALL_PACKAGES` (только для обновления в приложении)
- Зависимостей нет, кроме стандартной библиотеки Kotlin
- Сеть: только HTTPS, только к `open-meteo.com` и `github.com`
- С устройства уходят только координаты выбранного места в [Open-Meteo](https://open-meteo.com). Никаких идентификаторов устройства или рекламы

## Установка

1. Скачайте `Weather.apk` со страницы [Releases](../../releases/latest)
2. Откройте файл и разрешите установку, если Android спросит
3. Следующие версии обновляются внутри приложения
